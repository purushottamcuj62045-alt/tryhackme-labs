# Web Security

How web applications are attacked and how those attacks surface in server logs and traffic.

5 rooms · ~5 hours · [back to index](../README.md)

| Room | Difficulty | Format | Time | Description |
|---|---|---|---|---|
| [Web Security Essentials](https://tryhackme.com/room/websecurityessentials) | Easy | Walkthrough | 1h | Learn how the web works, common website security risks, and protections for a safer internet. |
| [Detecting Web Attacks](https://tryhackme.com/room/detectingwebattacks) | Easy | Walkthrough | 1h | Explore web attacks and detection methods through log and network traffic analysis. |
| [Detecting Web Shells](https://tryhackme.com/room/detectingwebshells) | Easy | Walkthrough | 1h | Explore web shell detection by analyzing logs, file systems, and network traffic. |
| [Detecting Web DDoS](https://tryhackme.com/room/detectingwebddos) | Easy | Walkthrough | 1h | Explore denial-of-service attacks, detection techniques, and strategies for protection. |
| [Guided Pentest: Web](https://tryhackme.com/room/guidedpentestweb) | Easy | Walkthrough | 1h | Learn web app pentesting by chaining vulnerabilities from recon to full server compromise. |

`Web` · `Web application security` · `Log analysis` · `Wireshark` · `Network traffic analysis` · `Linux` · `Threat hunting` · `Splunk` · `Nmap` · `Gobuster` · `Application penetration testing`
