# Threat Intelligence & Frameworks

The models analysts reason with — Kill Chain, Unified Kill Chain, Pyramid of Pain, MITRE ATT&CK — plus practical artefact enrichment.

8 rooms · ~6 hours · [back to index](../README.md)

| Room | Difficulty | Format | Time | Description |
|---|---|---|---|---|
| [Pyramid Of Pain](https://tryhackme.com/room/pyramidofpainax) | Easy | Walkthrough | 30m | Learn what the Pyramid of Pain is and how it ranks indicators by how painful they are for an adversary to change. |
| [Cyber Kill Chain](https://tryhackme.com/room/cyberkillchainzmt) | Easy | Walkthrough | 45m | The Cyber Kill Chain framework is designed for identification and prevention of the network intrusions. You will learn what the adversaries need to do in order to achieve their goals. |
| [Unified Kill Chain](https://tryhackme.com/room/unifiedkillchain) | Easy | Walkthrough | 40m | The Unified Kill Chain is a framework which establishes the phases of an attack, and a means of identifying and mitigating risk to IT assets. |
| [MITRE](https://tryhackme.com/room/mitre) | Medium | Walkthrough | 1h | Explore the various resources that MITRE has made available to the cyber security community. |
| [Intro to Cyber Threat Intel](https://tryhackme.com/room/cyberthreatintel) | Easy | Walkthrough | 45m | Introducing cyber threat intelligence and related topics, such as relevant standards and frameworks. |
| [File and Hash Threat Intel](https://tryhackme.com/room/fileandhashthreatintel) | Easy | Walkthrough | 1h 4m | This room seeks to teach on enriching file and hash artefacts using threat intelligence. |
| [IP and Domain Threat Intel](https://tryhackme.com/room/ipanddomainthreatintel) | Medium | Walkthrough | 1h | A look into enriching IP and domain insights with open source threat intelligence. |
| [Invite Only](https://tryhackme.com/room/invite-only) | Easy | Challenge | 1h | Extract insight from a set of flagged artefacts, and distil the information into usable threat intelligence. |
